# 🌌 `02 // ABOUT ME`

I'm a passionate developer who enjoys transforming ideas into **clean, responsive, interactive and visually engaging web experiences**.

My programming journey started with **C**, which helped me build a strong foundation in programming logic. I then explored **C++**, Object-Oriented Programming and **Data Structures & Algorithms**.
